# Sound Beep Solo - 电子提示音可视化生成器

一个纯原生 JavaScript 开发的电子提示音生成器，支持频率、波形、音量调节，实时波形预览，以及序列编辑和 WAV 导出功能。

## 功能特性

✨ **核心功能**
- 🎵 频率调节 (20Hz - 20000Hz)
- 📊 四种波形选择：方波、正弦波、锯齿波、三角波
- 🔊 音量控制 (1% - 100%)
- ⏱️ 时长和间隔设置
- 🎨 实时波形可视化预览

📝 **序列编辑**
- 添加多个音调到序列
- 编辑序列中每个音调的参数
- 试听单个音调或整个序列
- 音调排序和删除
- 序列时长统计

💾 **数据导出**
- 导出为 WAV 音频文件
- 导出/导入 JSON 配置文件
- 多个预设模板

🎯 **预设模板**
- 基础提示音
- 警报音
- 开始提示
- 计圈提示
- 双响提示
- 三响提示
- 递增音阶
- 递减音阶
- SOS 摩尔斯码

## 使用方法

### 在线使用
直接在浏览器中打开 `index.html` 文件即可使用。

### 本地运行
1. 克隆或下载项目
2. 双击 `index.html` 打开
3. 开始创作你的提示音！

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和响应式布局
- **原生 JavaScript (ES5+)** - 业务逻辑
- **Web Audio API** - 音频生成和播放
- **Canvas API** - 波形可视化
- **File API** - 文件导出/导入
